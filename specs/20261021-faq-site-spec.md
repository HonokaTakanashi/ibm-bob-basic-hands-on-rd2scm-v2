## 主な仕様

### FAQデータ（`faq-data.js`）

* グローバル変数 `FAQ_DATA` にカテゴリ配列を保持する。
* 構造:
  * カテゴリ: `{ id, title, items }`
  * 項目: `{ question, answer }`
  * `answer` は段落・箇条書き・補足を表現できる構造化データ（ブロック配列）とする。
    * `{ type: "p", text }`
    * `{ type: "ul", items: [text, ...] }`
  * 太字・インラインコードは、インライン要素の配列 `[{ text, bold?, code? }]` で表現する。
* カテゴリ（`qa.md` の見出し対応）:
  * 一般（General）: 5問
  * 使い方（Usage）: 8問
  * 高度な機能（Advanced Features）: 2問
  * トラブルシューティング（Troubleshooting）: 2問
* 翻訳方針:
  * 語調は「です・ます調」
  * 製品名・固有名詞（Bob、MCP、VS Code、Model Context Protocol 等）は原文のまま
  * コード表記（`/`、`@/src/file.ts`、`@problems`、`.bob/rules/`、Ctrl/Cmd + Z）は原文のまま
  * 略称（SPI、PHI、ITAR、APP、PAN）は原文のまま

### 表示・操作（`script.js`）

* 起動時に `FAQ_DATA` からカテゴリ見出しと質問一覧をDOMとして生成する。
* 質問は `<button>` による見出しと回答領域のアコーディオンで構成し、クリック・Enter・Spaceで開閉する。
* 検索ボックスの入力に応じて、質問文・回答文を対象に即時絞り込みを行う。
  * 前後の空白を除去し、大文字小文字を区別せず部分一致で判定する。
  * 一致する質問が0件のカテゴリ見出しは非表示にする。
  * 検索語が空の場合は全件を表示する。
* 一致件数が0件の場合は空状態メッセージを表示する。

## 制約・非機能要件

* 素のHTML/CSS/JavaScriptのみ。ビルド不要、外部通信なし、`file://` で動作する。
* `<script type="module">` や `fetch` を使用しない（`file://` での制約回避のため、通常の `<script>` タグで読み込む）。
* DOM生成は `createElement` と `textContent` を使用し、FAQ本文を `innerHTML` に挿入しない（XSS対策）。
* フォントはシステムフォント（`"Noto Sans JP"`, `"Hiragino Sans"`, `"Yu Gothic"`, `sans-serif` 等）を使用し、外部フォントを読み込まない。
* アクセシビリティ: `aria-expanded`、`aria-controls`、検索ボックスの `<label>`、キーボード操作、フォーカス表示を備える。
* `<html lang="ja">` を指定する。

## UI・画面仕様

### 対象画面

* FAQトップページ（`index.html`）1ページのみ。

### 画面構成・表示項目

上から順に以下を配置する。

1. ヘッダー: タイトル「よくある質問」、サブタイトル「Bobに関するよくある質問と回答をまとめています。」
2. 検索ボックス: ラベル「キーワードで検索」、プレースホルダー「例: モード、MCP、コマンド」
3. 検索結果の件数表示（スクリーンリーダー向けの `aria-live`）
4. カテゴリセクション（見出し + 質問アコーディオン一覧）× 4
5. 空状態メッセージ領域（通常は非表示）
6. フッター: 「このFAQは qa.md を元に日本語化したものです。」

### 操作・画面遷移

* 質問見出しのクリック/Enter/Space: 該当回答の開閉（独立して開閉、複数同時に開ける）
* 検索ボックスへの入力: 即時絞り込み
* 検索中に一致した質問は、回答を自動で開いた状態で表示する。
* ページ遷移なし。

### 表示状態

* 初期表示: 全カテゴリ・全質問を表示、回答はすべて閉じた状態
* 検索中: 一致した質問のみ表示し、回答を開いた状態にする
* 空状態: 「該当する質問が見つかりませんでした。別のキーワードでお試しください。」を表示
* 読み込み中・エラー: 静的データのため設けない

### 入力・バリデーション

* 検索ボックス: 自由入力。前後の空白を除去、大文字小文字を区別しない部分一致。
* 文字数上限・必須チェックは設けない（空の場合は全件表示）。

### デザイン要件

* IBM風: 背景は白とライトグレー（`#f4f4f4` 程度）、文字は濃いグレー（`#161616` 程度）、アクセントはIBM Blue（`#0f62fe`）
* 本文幅は最大 約800px で中央寄せ。
* レスポンシブ: モバイル（約360px）からデスクトップ（約1280px以上）まで横スクロールなしで表示。
* タップ領域は44px以上の高さを確保する。
* フォーカスリングを明示（IBM Blue）。
* コントラスト比はWCAG AA相当を満たす。

## リスク・懸念点

* 翻訳は機械的な翻訳に近く、専門用語の訳語が公式の日本語表記と異なる可能性がある。
* `qa.md` が更新された場合、`faq-data.js` への手動反映が必要（自動同期は対象外）。
* 「SPI」「PHI」などの略称は原文のまま残すため、読者によっては補足が必要になる可能性がある。
