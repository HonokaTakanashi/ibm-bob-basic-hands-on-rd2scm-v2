## 実装手順

1. **データ構造と日英コンテンツの定義**:
   - `qa.md` の全4カテゴリ（General, Usage, Advanced Features, Troubleshooting）、全16問のQ&Aを日本語に翻訳。
   - JavaScript定数オブジェクトとして、日英のカテゴリ名・質問・回答（HTMLタグ/リスト構造含む）を構造化定義する。

2. **HTML基本構造の構築**:
   - `<header>`: `bob.svg` ロゴ、タイトル、言語切り替えスイッチ（JA / EN）。
   - `<section class="hero">`: タイトル・説明文、検索バー（入力欄、アイコン、クリアボタン）。
   - `<nav class="category-tabs">`: カテゴリ切り替え・クイックジャンプ用タブ。
   - `<section class="actions">`: 「すべて開く」「すべて閉じる」ボタン、検索件数表示。
   - `<main class="faq-container">`: 動的レンダリング用コンテナ、および検索ヒットなし用の空状態表示エリア。
   - `<footer>`: コピーライトおよび関連リンク。

3. **CSSデザインとスタイリング**:
   - IBM Carbon Design Systemのカラーパレット（IBM Blue #0f62fe、ダークグレー #161616、ライトグレー #f4f4f4、ボーダー #e0e0e0 等）に準拠したモダンデザイン。
   - IBM Plex Sans およびシステムUIフォントスタックの指定。
   - アコーディオン開閉のアニメーション（トランジション）、ホバーエフェクト。
   - メディアクエリによるレスポンシブ対応（スマホ・タブレット・PC）。

4. **JavaScriptロジックの実装**:
   - **状態管理**: 現在の言語（`currentLang = 'ja'`）、検索キーワード（`searchQuery = ''`）、選択カテゴリ（`selectedCategory = 'all'`）。
   - **レンダリング関数**: 状態（言語、検索語、カテゴリ）に応じたFAQリストの動的生成。
   - **アコーディオン制御**: クリックによる開閉トグル、個別制御および一括開閉（すべて開く/閉じる）。
   - **リアルタイム検索**: 入力イベントに連動したフィルタリングおよびハイライト処理。
   - **言語切り替え**: 言語変更時のUI文言・FAQリストの再描画。

5. **動作確認と検証**:
   - ブラウザ表示・機能動作確認（言語切替、検索、開閉、レスポンシブ）。
   - 仕様書の完了条件との照合。

## GUI実装

* 対象コンポーネント:
  - Header（ロゴ、サイトタイトル、言語スイッチャー）
  - Search & Filter Bar（検索入力欄、クリアボタン、一括開閉ボタン、カテゴリタブ）
  - FAQ Accordion List（カテゴリ見出し、質問カード、開閉矢印、回答パネル）
  - Empty State（検索結果0件時メッセージ）
  - Footer
* スタイル: CSS3（Flexbox, CSS Grid, CSS Variables, Transitions）
* 状態管理: クライアントサイドVanilla JSによるステート管理（Lang, Search, ActiveCategory, OpenItems）
* 画面遷移: なし（シングルページ）
* レスポンシブ対応:
  - PC（> 768px）: 2カラムまたはゆったりとした幅広カードレイアウト
  - モバイル（<= 768px）: 1カラム、タップしやすい余白とフォントサイズ

## テストの追加・更新

* 単一静的HTMLのため、ブラウザでのエンドツーエンド動作検証およびHTML/JSのシンタックス・整合性チェックを実施。

## 検証計画

1. **表示検証**:
   - `index.html` を開き、ヘッダーに `bob.svg` が正しく表示されること。
   - 4つのカテゴリと16問のQ&Aが欠落なく表示されること。
2. **言語切り替え検証**:
   - 日本語 ⇔ 英語の切り替えを行い、ヘッダー・検索バー・カテゴリ名・全Q&Aが即座に切り替わること。
3. **アコーディオン検証**:
   - 質問をクリックして回答が開閉すること。
   - 「すべて開く」「すべて閉じる」が正しく全項目に適用されること。
4. **検索検証**:
   - キーワード入力で該当する質問/回答がリアルタイムに絞り込まれること。
   - 存在しない文字列を入力した際に空状態が表示されること。
   - クリアボタンで検索がリセットされること。
5. **レスポンシブ検証**:
   - 画面幅を縮小してもレイアウトが崩れず操作可能であること。
