## 背景・目的

既存の Bob FAQ サイトに Bob ブランドを反映させるため、以下を追加する。

1. ヘッダー左上に Bob の SVG ロゴを挿入
2. ロゴに IBM Bob 製品ページへのリンクを追加
3. サイトテーマカラーを Bob SVG のカラーに統一
4. ダークテーマ（ライト/ダーク切り替えトグル + システム設定自動対応）を追加

## 現在の挙動

* ヘッダーはテキスト（h1 タイトル・サブタイトル）のみ
* テーマカラーは IBM Carbon Blue (`#0f62fe`) のみ
* ダークテーマ非対応

## 期待する挙動

* ヘッダー左上に `bob.svg` が表示され、クリックで `https://www.ibm.com/products/bob` へ遷移（新規タブ）
* テーマカラーは Bob SVG の Blue `#0f62fe` をメイン、Purple `#a56eff` をサブアクセントに統一
* ヘッダー右端にダークテーマトグルボタンが表示され、クリックでライト/ダーク切り替えが可能
* `prefers-color-scheme: dark` によりシステム設定を自動反映（初期状態）

## 対象範囲・対象外

### 対象範囲

* `index.html`: ヘッダー構造変更（ロゴ・リンク・トグルボタン追加）

### 対象外

* `script.js`、`faq-data.js`: ロジック変更なし
* FAQ コンテンツ本体の変更

## 利用者・影響システム

* Bob FAQ サイト閲覧ユーザー

## 主な仕様

### 1. Bob ロゴ

* `bob.svg` をヘッダー内に `<img>` タグで挿入
* 高さ 48px、幅は自動
* `<a>` タグでラップし `href="https://www.ibm.com/products/bob"` `target="_blank"` `rel="noopener noreferrer"` を設定
* `alt="Bob"` を付与

### 2. テーマカラー

| 変数 | 現行値 | 変更後 |
|---|---|---|
| `--accent` | `#0f62fe` | `#0f62fe`（変更なし） |
| `--accent-hover` | `#0043ce` | `#0043ce`（変更なし） |
| `--accent-sub` | なし | `#a56eff`（新規追加） |
| `--header-border` | `--accent` 使用 | グラデーション（Blue → Purple）に変更 |

* ヘッダーのトップボーダーを Blue → Purple のグラデーションに変更してブランドを表現

### 3. ダークテーマ

* CSS カスタムプロパティで `[data-theme="dark"]` スコープのダーク用変数を定義
* `@media (prefers-color-scheme: dark)` でシステム設定自動対応
* ヘッダー右端にトグルボタン（🌙 / ☀️）を配置
* クリックで `<html>` の `data-theme` 属性を `"dark"` / `"light"` 切り替え
* ユーザー選択を `localStorage` に保存し、ページ再読み込み後も維持
* `<script>` をページ先頭（`<body>` 直後）でインラインで実行し、FOUC を防止

#### ダークテーマ用カラー変数

| 変数 | ライト | ダーク |
|---|---|---|
| `--bg` | `#ffffff` | `#161616` |
| `--bg-subtle` | `#f4f4f4` | `#262626` |
| `--border` | `#e0e0e0` | `#393939` |
| `--text` | `#161616` | `#f4f4f4` |
| `--text-secondary` | `#525252` | `#a8a8a8` |
| `--accent` | `#0f62fe` | `#78a9ff` |
| `--accent-hover` | `#0043ce` | `#a6c8ff` |
| `--code-bg` | `#e8e8e8` | `#393939` |
| `--accent-sub` | `#a56eff` | `#d4bbff` |
