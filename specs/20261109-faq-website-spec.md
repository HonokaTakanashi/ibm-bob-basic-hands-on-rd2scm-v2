* 種別: 新規実装
* 作成日時: 2026-11-09T05:24:52Z
* 更新日時: 2026-11-09T05:24:52Z

* ステータス: Approved

## 背景・目的

リポジトリ内に存在する `qa.md` のFAQデータをもとに、バックエンドサーバーを必要とせず、ブラウザで直接開いて閲覧・利用可能な日本語・英語対応の静的FAQ Webサイトを作成する。

## 現在の挙動

* リポジトリには英語のマークダウン形式のFAQファイル（`qa.md`）とロゴ画像（`bob.svg`）のみが存在する。
* WebブラウザでグラフィカルにFAQを閲覧・検索・操作できるUIは存在しない。

## 期待する挙動

* 単一のHTMLファイル（`index.html`）をブラウザで開くだけで、FAQサイトとして完全に動作する。
* `qa.md` に記載されている全4カテゴリ・全16件のQ&Aが正確に表示される。
* 日本語および英語の表示切り替えが可能である。
* リアルタイム検索バーにより、キーワードで質問および回答を高速に絞り込める。
* アコーディオンUIにより、クリックで各質問の回答を展開・折りたたみできる。
* レスポンシブ対応により、PC・タブレット・スマートフォンの各画面サイズで快適に閲覧できる。

## 対象範囲・対象外

### 対象範囲

* `index.html` の新規作成（HTML構造、スタイルCSS、動的スクリプトJSを1ファイルに集約）
* `bob.svg` のロゴ画像の表示
* `qa.md` に基づくFAQデータ定義（日英対訳データ）
* カテゴリナビゲーション、アコーディオン開閉、キーワード検索、言語切り替え機能の実装
* 仕様書（`specs/20261109-faq-website-spec.md`）および実装計画書（`specs/20261109-faq-website-plan.md`）の作成

### 対象外

* 外部APIサーバーやNode.jsなどのバックエンドサーバーの実装
* npm / Vite 等のビルドステップやパッケージ依存関係の導入
* `qa.md` 原本ファイルの変更・削除

## 利用者・影響システム

* 利用者: IBM Bobの利用方法や仕様を確認したいユーザーおよび開発者
* 影響システム: クライアントサイドのWebブラウザ（Chrome, Safari, Edge, Firefox等）

## 主な仕様

1. **データ構造**:
   - `qa.md` の内容を構造化したJavaScriptオブジェクト配列として保持（カテゴリ、質問、回答、日英テキスト）。
   - 4カテゴリ:
     - General（概要 / 全般）: 5問
     - Usage（使い方）: 8問
     - Advanced Features（高度な機能）: 2問
     - Troubleshooting（トラブルシューティング）: 2問
2. **言語切り替え**:
   - ヘッダー内の切り替えボタンにより、即座にUI文言およびFAQコンテンツの言語（日本語/英語）が切り替わる。
   - デフォルト表示言語は日本語。
3. **アコーディオン機能**:
   - 質問タイトルをクリックすると該当の回答がスムーズに展開/折りたたみされる。
   - 開閉アイコン（矢印またはプラス/マイナス）が状態に応じて変化する。
   - 「すべて開く」「すべて閉じる」ボタンの提供。
4. **キーワード検索**:
   - 入力されたキーワードでリアルタイムにフィルタリング。
   - 質問文または回答文にキーワードが含まれる項目のみを表示。
   - マッチする項目がない場合は「検索結果が見つかりませんでした」の空状態を表示。
   - 入力クリアボタンの提供。
5. **カテゴリナビゲーション**:
   - カテゴリタブまたはサイドバー/上部リンクにより、目的のカテゴリへ素早くジャンプまたは絞り込み可能。

## 制約・非機能要件

* **完全静的**: 外部依存（外部CDN等）が万一オフラインであっても基本機能が動作するよう、標準Web標準技術（HTML5/CSS3/ES6+ Vanilla JS）で実装する。
* **フォント**: システムフォントおよびWebフォント（IBM Plex Sansフォールバック）を使用し、視認性を確保。
* **デザイン**: IBM Carbon Design / Bobのトーンに準拠した青・白・グレー基調の洗練されたUI。
* **アクセシビリティ**: セマンティックHTML（`<main>`, `<section>`, `<details>` / `<button>` など）の採用、キーボード操作対応。

## UI・画面仕様

### 対象画面

* FAQトップ画面（シングルページ: `index.html`）

### 画面構成・表示項目

1. **ヘッダーエリア**:
   - ロゴ（`bob.svg`）
   - タイトル（例: 「IBM Bob FAQ」「よくあるご質問」）
   - 言語切り替えトグル（JA / EN）
2. **ヒーロー / 検索エリア**:
   - キャッチコピー（例: 「どのようなご用件でしょうか？」「必要な情報を検索できます」）
   - 検索入力フィールド（プレースホルダー、虫眼鏡アイコン、クリアボタン）
   - クイックアクション（「すべて展開」「すべて折りたたむ」）
3. **メインエリア**:
   - カテゴリナビゲーションタブ（すべて / General / Usage / Advanced / Troubleshooting）
   - FAQアコーディオン一覧（カテゴリ見出し、質問カード、回答コンテンツ、リスト表示）
   - 検索ヒット件数バッジ
4. **フッターエリア**:
   - コピーライト表記、リポジトリ・ドキュメントへのリンク

### 操作・画面遷移

* **言語切り替えクリック**: ページ全体の言語表示が切り替わる（リロードなし）。
* **検索ボックス入力**: キー入力ごとに一覧がフィルタリングされる。
* **カテゴリタブクリック**: 指定カテゴリのみ表示、または指定カテゴリ位置へスクロール。
* **質問クリック**: アコーディオンが開閉する。

### 表示状態

* **初期状態**: 全カテゴリ・全質問が表示。アコーディオンは閉じ状態（または見通しを良くするため最初の項目のみオープン）。
* **検索中（該当あり）**: 一致したFAQ項目のみ表示され、親カテゴリが表示される。
* **検索結果ゼロ（空状態）**: 「該当する質問が見つかりませんでした。別のキーワードをお試しください。」等のメッセージと検索クリアボタンを表示。

### 入力・バリデーション

* 検索入力: 任意の文字列。特別なバリデーションエラーは不要（部分一致検索）。

### デザイン要件

* 配色: IBMブルー（#0f62fe等）、背景色（#f4f4f4 / #ffffff）、テキスト（#161616 / #525252）。
* レスポンシブ対応: モバイル（〜768px）およびデスクトップ（769px〜）に最適化したレイアウト。
* トランジション: アコーディオン開閉やホバー時のスムーズなアニメーション。
